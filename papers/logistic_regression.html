Instructions & Notation

  1. Attempt all questions. Justify every step.
  2. Logistic model: $\sigma(z) = 1/(1+e^{-z})$, $z = \mathbf w^\top \mathbf x + b$, labels $y \in \{0,1\}$.
  3. Log-loss for one example: $\ell = -\big[y\log p + (1-y)\log(1-p)\big]$, $p = \sigma(z)$.

Problems

Problem 1 [6]

Prove the sigmoid identities: $\sigma(-z) = 1-\sigma(z)$ and $\sigma'(z) = \sigma(z)(1-\sigma(z))$. Sketch $\sigma$ and mark $\sigma(0)$.

Problem 2 [7]

For $p = \sigma(z)$, the log-odds (logit) is $\log \frac{p}{1-p}$.

  1. Show the logit of $\sigma(z)$ is exactly $z$.
  2. If $z$ increases by $\Delta$, by what factor are the odds multiplied?

Problem 3 [8]

Derive the gradient of the single-example log-loss w.r.t. $z$: show $\partial \ell / \partial z = \sigma(z) - y$. Hence write $\nabla_{\mathbf w}\,\ell$ and $\partial \ell/\partial b$.

Problem 4 [8]

With data $\{(1,1),(2,2),(3,0)\}$ (1-D feature $x$, label $y$) and model $p=\sigma(wx)$, $b=0$:

  1. Write the total negative log-likelihood $J(w)$.
  2. Show $J$ is convex in $w$ by computing $J''(w) \ge 0$.

Problem 5 [7]

The decision boundary of binary logistic regression is $\{\mathbf x : \mathbf w^\top \mathbf x + b = 0\}$.

  1. Prove this set is a hyperplane and that $p \ge 1/2$ on exactly one closed half-space.
  2. Give a 2-D dataset that is not linearly separable, with proof.

Problem 6 [8]

Let classes be Gaussian with shared variance: $x\mid y=1 \sim \mathcal N(\mu_1,\sigma^2)$, $x\mid y=0 \sim \mathcal N(\mu_0,\sigma^2)$, priors $\pi_1,\pi_0$.

  1. Show the posterior $P(y=1\mid x)$ is logistic in $x$ and identify $w,b$.
  2. What changes if the variances differ? Name the resulting classifier form.

Problem 7 [8]

With $L_2$ penalty $J_\lambda = J + \frac{\lambda}{2}\lVert\mathbf w\rVert^2$:

  1. Write the gradient update (learning rate $\alpha$).
  2. Explain, via a $2$-D contour sketch argument, why large $\lambda$ shrinks $\lVert\mathbf w\rVert$ and flattens predicted probabilities toward $1/2$.

Problem 8 [10]

Calibration. A model outputs $p_i$ on $n$ examples with outcomes $y_i$.

  1. Define perfect calibration informally and mathematically ($P(Y=1 \mid \hat P = p) = p$).
  2. Construct a small numeric example where accuracy is $100\%$ yet the model is badly miscalibrated, and propose one remedy (e.g. Platt scaling / temperature).

Solutions (Outlines)

Solution 1. Algebra from $1/(1+e^{-z})$; derivative via quotient rule; $\sigma(0)=1/2$.

Solution 2. $\log(\sigma/(1-\sigma)) = \log e^{z} = z$; odds multiply by $e^{\Delta}$.

Solution 3. Chain rule on $-[y\log\sigma+(1-y)\log(1-\sigma)]$ gives $\sigma-y$; $\nabla_{\mathbf w}\ell = (\sigma-y)\mathbf x$.

Solution 4. $J = \sum \log(1+e^{wx_i}) - y_iwx_i$; $J'' = \sum x_i^2\sigma(1-\sigma)\ge 0$.

Solution 5. Linear equation defines hyperplane; e.g. XOR $\{(0,0),(1,1)\}$ vs $\{(0,1),(1,0)\}$ is inseparable by convexity argument.

Solution 6. Log posterior-odds $= wx+b$ with $w=(\mu_1-\mu_0)/\sigma^2$; unequal variances give a quadratic (QDA) boundary.

Solution 7. $\mathbf w \gets \mathbf w - \alpha(\nabla J + \lambda\mathbf w)$; penalty pulls optimum toward origin, shrinking logits.

Solution 8. E.g. always predict $0.51$ on positives and $0.49$ on negatives: $100\%$ accurate at threshold $0.5$ but probabilities uninformative; refit $p=\sigma(a z+b)$ on held-out data.

01

"The Ghost Measurements"

Iterative Sigma Purification · Normal CDF from Scratch · Outlier Elimination
Normal PDF 68-95-99.7 Taylor Series erf Iterative Algorithm
Difficulty
★★ ★★ ★
Background

A lab claims its instrument measures a normally distributed quantity. However, a saboteur has silently injected at most ⌊N/4⌋ corrupted readings into the dataset before you received it. Your job is to recover the true distribution and answer probability queries — without any math library.

The Setup

Define a reading as an outlier with respect to parameters (μ, σ) if it falls outside (μ − 3σ, μ + 3σ). The Iterative Sigma Purification algorithm works as follows:

Algorithm
repeat:
    compute mean μ and std σ of current dataset S
    remove all x ∈ S where |x - μ| > 3σ
until S does not change

By the 99.7% rule, at most 0.3% of genuine readings get removed per iteration — but outliers get eliminated aggressively. This converges in O(log N) iterations.

Task

Given N readings and Q queries of the form (a, b), output P(a ≤ X ≤ b) to 6 decimal places, where X follows the recovered N(μ, σ²). You may not use any built-in erf, erfc, or normal distribution functions. You must implement the normal CDF yourself via Taylor series.

Key Formulae
erf(x) = (2/√π) · Σ (-1)ⁿ · x^(2n+1) / [n! · (2n+1)] // Taylor series Φ(z) = (1/2) · [1 + erf(z / √2)] // Normal CDF from erf P(a ≤ X ≤ b) = Φ((b-μ)/σ) - Φ((a-μ)/σ) // Probability query
Input / Output Format

Line 1: N Q  ·  Next N lines: one real per line  ·  Next Q lines: a b

Sample Input
12 3 98.2 101.3 99.7 100.1 350.0 100.5 98.9 99.2 101.1 -280.0 100.3 99.8 95.0 105.0 85.0 115.0 99.0 101.0
Sample Output
99.900000 0.938083 0.999970 1.000000 0.712816
Constraints
N (readings)10 ≤ N ≤ 100,000
Q (queries)1 ≤ Q ≤ 10,000
readings∈ [−10⁶, 10⁶]
outliers injectedat most ⌊N/4⌋
erf Taylor terms50 terms sufficient
💡 The AHA Moment

The 68-95-99.7 rule is not just a memorization fact — it's an algorithmic convergence guarantee. Each iteration removes true outliers while keeping ≥99.7% of genuine data. This proves the algorithm must terminate in O(log N) steps. The moment you realize the rule proves termination — not just describes probabilities — is the aha.

Python 3
import math

def erf_taylor(x, terms=50):
    # Implement erf via Taylor series expansion
    result = 0.0
    for n in range(terms):
        sign   = (-1)**n
        num    = x**(2*n+1)
        den    = math.factorial(n) * (2*n+1)
        result += sign * num / den
    return (2 / math.sqrt(math.pi)) * result

def normal_cdf(z):
    return 0.5 * (1 + erf_taylor(z / math.sqrt(2)))

def prob_between(a, b, mu, sigma):
    za = (a - mu) / sigma
    zb = (b - mu) / sigma
    return normal_cdf(zb) - normal_cdf(za)

def purify(data):
    S = data[:]
    while True:
        mu    = sum(S) / len(S)
        sigma = math.sqrt(sum((x-mu)**2 for x in S) / len(S))
        new_S = [x for x in S if abs(x-mu) <= 3*sigma]
        if len(new_S) == len(S): return mu, sigma
        S = new_S

"Bridging Binomial to Bell"

Normal Approximation · Exact Binomial CDF · Berry-Esseen Theorem · Continuity Correction
Normal Approx Log-Space Arithmetic Berry-Esseen Binary Search
Difficulty
★★ ★★ ★
Background

The normal approximation to the binomial is taught as "works when np > 5." But how wrong is it exactly for a given (n, p)? And what is the precise effect of the continuity correction? This problem forces you to compute it rigorously.

Task

Given rational p = a/b and tolerance ε, find the minimum integer n such that for every k ∈ {0, 1, ..., n}:

|F_binom(k; n, p) − Φ((k + 0.5 − np) / √(np(1−p)))| ≤ ε // The +0.5 is the continuity correction — omit it and required n grows ~4×
Exact Binomial CDF (Log-Space Recursion)
log P(X=0) = n · log(1−p) log P(X=j) = log P(X=j−1) + log(n−j+1) − log(j) + log(p) − log(1−p) // Accumulate via log-sum-exp for numerical stability // Berry-Esseen bound: max error ≤ 0.5 / √n → upper bound for search space
Sample Input 1
1 2 0.01
Sample Output 1
n = 28 (violates) Last violating k: k=14 error = 0.010021 First satisfying n: 29 max error = 0.009871 at k=14
Sample Input 2
1 10 0.01
Sample Output 2
n = 73 (violates) Last violating k: k=7 error = 0.010156 First satisfying n: 74 max error = 0.009923 at k=8
Constraints
p = a/b1 ≤ a < b ≤ 100
ε10⁻⁸ ≤ ε ≤ 0.1
n_minguaranteed ≤ 10⁷
Subtletymax error over k is NOT monotone in n
💡 The AHA Moment

Without the continuity correction, the required n is roughly 4× larger. The correction aligns the discrete bar centers with the continuous curve. Most students learn this as a mechanical rule, but the moment you see the error profile change shape when you add +0.5 — the systematic bias evaporates — that is the aha. The correction isn't a trick; it compensates for the fundamental discrete-vs-continuous mismatch at bar boundaries.

Python 3
import math

def log_binom_pmf(n, p):
    # log P(X=k) for k=0..n via stable recursion
    lp = [0.0] * (n+1)
    lp[0] = n * math.log(1-p)
    for k in range(1, n+1):
        lp[k] = (lp[k-1]
                  + math.log(n-k+1) - math.log(k)
                  + math.log(p)     - math.log(1-p))
    return lp

def max_approx_error(n, p):
    mu    = n * p
    sigma = math.sqrt(n*p*(1-p))
    cdf   = []
    run   = 0.0
    for lp in log_binom_pmf(n, p):
        run += math.exp(lp)
        cdf.append(min(run, 1.0))
    max_e, wk = 0.0, 0
    for k, fk in enumerate(cdf):
        z = (k + 0.5 - mu) / sigma  # continuity correction
        e = abs(fk - normal_cdf(z))
        if e > max_e: max_e, wk = e, k
    return max_e, wk

"The Invisible Boundary"

Two-Population Gaussians · Optimal Decision Threshold · Newton's Method · Disconnected Classifiers
Normal PDF Newton's Method Global Optimization Transcendental Equations
Difficulty
★★ ★★ ★
Background

A hospital measures a biomarker. Healthy patients have X ~ N(μ₁, σ₁²); diseased patients have X ~ N(μ₂, σ₂²). The population proportions are π and (1−π). Find the optimal threshold t that minimizes total misclassification probability.

The Objective Function
MCP(t) = π · [1 − Φ(z₁(t))] + (1−π) · Φ(z₂(t)) where z₁(t) = (t−μ₁)/σ₁ and z₂(t) = (t−μ₂)/σ₂ // Optimality condition (set dMCP/dt = 0): (π/σ₁) · φ(z₁(t)) = ((1−π)/σ₂) · φ(z₂(t)) // φ = standard normal PDF. No closed form → Newton's method // When σ₁ ≠ σ₂, this may have TWO solutions → two-region classifier

💡 The AHA Moment

When σ₁ = σ₂, one threshold suffices. But when σ₁ ≠ σ₂, the two Gaussian PDFs intersect at two points, creating a bizarre situation: the "healthy" region is a disconnected set — a union of two intervals. This means a patient is classified as diseased if their biomarker is either too low or too high. This two-threshold phenomenon falls naturally out of the math but is never taught in intro stats.

Python 3
def MCP(t, m1,s1,m2,s2,pi):
    z1 = (t-m1)/s1;  z2 = (t-m2)/s2
    return pi*(1-Phi(z1)) + (1-pi)*Phi(z2)

def dMCP(t, m1,s1,m2,s2,pi):
    return -pi*phi((t-m1)/s1)/s1 + (1-pi)*phi((t-m2)/s2)/s2

def find_all_thresholds(m1,s1,m2,s2,pi):
    # Scan for sign changes in dMCP across the support
    lo  = min(m1,m2) - 5*max(s1,s2)
    hi  = max(m1,m2) + 5*max(s1,s2)
    pts = [lo + (hi-lo)*i/10000 for i in range(10001)]
    roots = []
    for i in range(len(pts)-1):
        if dMCP(pts[i],m1,s1,m2,s2,pi)*dMCP(pts[i+1],m1,s1,m2,s2,pi) < 0:
            # Bracket found → refine with Newton

"The Percentile Ladder Tournament"

Truncated Normal · Inverse Mills Ratio · Multi-Stage Selection · Probit Function
Truncated Normal Inverse CDF Recurrence Conditional Probability
Difficulty
★★ ★★ ★
Background

In each tournament round, the top p% of scorers advance. Scores are normally distributed. Critical insight: keeping only the top fraction produces a truncated normal distribution — the next round's population is NOT the same family as before; its mean and variance shift via the Inverse Mills Ratio.

Truncated Normal Recurrence
λ = φ(z_p) / (1 − Φ(z_p)) // Inverse Mills Ratio; z_p = Φ⁻¹(1−p_keep) μ_new = μ + σ · λ σ²_new = σ² · [1 − z_p · λ − λ²] // Note: σ² DECREASES each round — survivors are more homogeneous // Survival prob of individual x₀ requires conditional CDF composition, NOT simple product

Sample Input

Sample Output

Constraints

💡 The AHA Moment

Students expect survival probability to be a simple product of round probabilities. It is NOT — because surviving round 1 updates your rank within the surviving pool. The correct computation is a composition of conditional probabilities through truncated normal CDFs. Also: σ² strictly decreases each round — elite survivors converge toward a single score. This is why real-world competition winners all seem nearly equally talented; the truncation squeezes variance toward zero.

Python 3
def Phi_inv(p, lo=-10, hi=10, tol=1e-10):
    # Bisection-based probit function
    while hi-lo > tol:
        mid = (lo+hi)/2
        if Phi(mid) < p: lo = mid
        else: hi = mid
    return (lo+hi)/2

def trunc_params(mu, sigma, p_keep):
    zp  = Phi_inv(1-p_keep)
    lam = phi(zp) / (1-Phi(zp))           # Mills ratio
    mu2 = mu + sigma*lam
    s2  = sigma**2*(1 - zp*lam - lam**2)
    return mu2, math.sqrt(max(s2,1e-15))

def survival_prob(x0, rounds, mu0, s0):
    # P(x0 survives all rounds) — conditional composition
    prob = 1.0
    mu, s = mu0, s0
    for p_keep in rounds:
        cutoff = mu + s*Phi_inv(1-p_keep)
        # P(x0 > cutoff) in ORIGINAL coordinates
        p_pass = 1 - Phi((cutoff-x0)/s0)
        # but we need conditional on already being above prev cutoff
        # --- COMPLETE THIS CONDITIONAL CHAIN ---
        mu, s = trunc_params(mu, s, p_keep)
    return prob

"When Uniforms Become Normal"

Central Limit Theorem · Irwin-Hall Distribution · Kolmogorov-Smirnov Distance · Convergence Rate
Uniform CLT KS Statistic Exact vs Simulated
Difficulty
★★ ★★ ★
Background

The CLT says the standardized sum of n IID Uniform(0,1) variables converges to N(0,1). But how fast? The Kolmogorov-Smirnov distance Dₙ measures the worst-case gap between the empirical CDF and the normal. You will compute it exactly via the Irwin-Hall distribution and verify via simulation.

Key Formulae
S_n = (Σ Uᵢ − n/2) / √(n/12) // Standardized sum of n Uniform(0,1) D_n = sup_x |F_{S_n}(x) − Φ(x)| // KS distance // Exact Irwin-Hall CDF (sum of n uniforms at point x_raw): P(S ≤ x) = (1/n!) · Σ_{k=0}^{⌊x⌋} (−1)^k · C(n,k) · (x−k)^n // Standardize: x_raw = z·√(n/12) + n/2, then apply above // Key finding: D_n ≈ C/n (not C/√n!) for uniform — superpolynomial convergence

Constraints

💡 The AHA Moment

Students expect CLT convergence at the Berry-Esseen rate O(1/√n). For the uniform distribution, convergence is O(1/n) — roughly twice as fast in log-log scale. This is because the uniform distribution is symmetric and has finite moments of all orders. The Berry-Esseen bound is not tight for well-behaved distributions. Seeing the convergence table and noticing the rate vastly outpaces 1/√n is the aha — one you can prove computationally before ever seeing the theory.

Python 3
import math, random

def irwin_hall_cdf(x, n):
    # Exact CDF of sum of n Uniform(0,1)
    if x <= 0: return 0.0
    if x >= n: return 1.0
    total = 0.0
    for k in range(int(x)+1):
        total += (-1)**k * math.comb(n,k) * (x-k)**n
    return total / math.factorial(n)

def std_irwin_hall_cdf(z, n):
    x = z*math.sqrt(n/12) + n/2
    return irwin_hall_cdf(x, n)

def ks_exact(n, num_pts=2000):
    zs = [-4+8*i/num_pts for i in range(num_pts+1)]
    return max(abs(std_irwin_hall_cdf(z,n)-Phi(z)) for z in zs)

def ks_simulate(n, M):
    zs = sorted(sum(random.random() for _ in range(n))
                for _ in range(M))
    zs = [(z-n/2)/math.sqrt(n/12) for z in zs]
    return max(abs((i+1)/M - Phi(z)) for i,z in enumerate(zs))

"The Exponential Renewal Oracle"

Exponential · Erlang-r · Poisson Connection · CLT Bridge · Convolution DP
Exponential Erlang-r CLT Bridge MLE Convolution DP
Difficulty
★★ ★★ ★
Background

A network processes packets. Each packet requires r exponential stages to complete (Erlang-r inter-arrival). This problem bridges all three distributions: Exponential arrivals → Erlang counting → Normal approximation (via CLT). You must estimate λ via MLE, compute exact Poisson probabilities for r=1, and handle the general Erlang case via convolution DP.

Three-Part Structure
// PART A: MLE for λ λ̂ = k / Σ Tᵢ // Maximum Likelihood Estimator // PART B: Poisson counts when r = 1 P(N = m) = (λ̂W)^m · e^(−λ̂W) / m! // PART C: Erlang-r CDF (r processing stages) F_r(x) = 1 − e^(−λx) · Σ_{j=0}^{r−1} (λx)^j / j! // P(exactly m completions in [0,W]) = F_r^{*m}(W) − F_r^{*(m+1)}(W) // where * denotes convolution — compute via DP on time grid // As r→∞: inter-arrival time → N(r/λ, r/λ²) by CLT // Arrival process becomes nearly deterministic!

💡 The AHA Moment

When r=1, Erlang → Exponential and counts → Poisson. As r→∞, the inter-arrival distribution becomes approximately Normal(r/λ, r/λ²) by the Central Limit Theorem, making packet arrivals nearly deterministic. This single problem traverses the entire journey: Exponential → Erlang → (CLT) → Normal. The three distributions of this lecture are secretly a single family parameterized by r. That unification — seeing all three as one — is the aha.

import math

def erlang_cdf(x, r, lam):
    # F_r(x) = 1 - e^(-λx) · Σ_{j=0}^{r-1} (λx)^j / j!
    if x <= 0: return 0.0
    lx  = lam * x
    s   = 0.0
    term = 1.0
    for j in range(r):
        s += term
        term *= lx / (j+1)
    return 1.0 - math.exp(-lx)*s

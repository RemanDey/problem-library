(c) Show that the inflection point of $g$ is the unique point where $g''(z)=0$, and that this point coincides exactly with the decision boundary $P(y=1\mid x)=1/2$.

Total: 10 points (3 + 4 + 3)

Problem 2 · Convex Analysis Gold

Strict Convexity of the Cross-Entropy Loss

Recall the cross-entropy (negative log-likelihood) loss $$J(\theta) = -\frac{1}{m}\sum_{i=1}^m \Big[y^{(i)}\log h_\theta(x^{(i)}) + (1-y^{(i)})\log(1-h_\theta(x^{(i)}))\Big], \quad h_\theta(x)=g(\theta^Tx).$$

(a) Derive the Hessian $\nabla^2 J(\theta)$ and show it can be written as $$\nabla^2 J(\theta) = \frac{1}{m}X^T S X, \qquad S = \mathrm{diag}\big(h_\theta(x^{(i)})(1-h_\theta(x^{(i)}))\big)_{i=1}^m,$$ where $X$ is the $m\times n$ design matrix with rows $x^{(i)T}$.

(b) Prove that $\nabla^2 J(\theta) \succeq 0$ (positive semidefinite) for every $\theta$, hence $J$ is convex.

(c) Prove that $J$ is strictly convex if and only if $X$ has full column rank $n$ (assuming no row of $X$ is such that $\theta^Tx^{(i)}\to\pm\infty$ trivially — i.e. away from the separable case treated in Problem 3). Exhibit an explicit $\theta$-direction along which $J$ is exactly flat (zero curvature) when $X$ is rank-deficient.

Total: 12 points (4 + 3 + 5)

Show full solution

Part (a)

From the lecture's per-example gradient, $\frac{\partial}{\partial \theta_j}\ell(\theta) = (y-h_\theta(x))x_j$ for the log-likelihood of one example; since $J=-\frac1m\sum_i \ell^{(i)}$, we get $$\nabla_\theta J(\theta) = \frac{1}{m}\sum_{i=1}^m (h_\theta(x^{(i)}) - y^{(i)})\, x^{(i)} = \frac{1}{m}X^T(h_\theta(X)-y).$$ Differentiate again with respect to $\theta$. Since $\frac{\partial}{\partial \theta} h_\theta(x^{(i)}) = h_\theta(x^{(i)})(1-h_\theta(x^{(i)}))\,x^{(i)}$ (chain rule through $g'=g(1-g)$), each term contributes a rank-one matrix: $$\nabla^2 J(\theta) = \frac{1}{m}\sum_{i=1}^m h_\theta(x^{(i)})(1-h_\theta(x^{(i)}))\, x^{(i)}x^{(i)T} = \frac{1}{m}X^TSX,$$ with $S$ diagonal as claimed, since $\sum_i s_i x^{(i)}x^{(i)T} = X^T \mathrm{diag}(s_i) X$ by direct index expansion.

Part (b)

For any vector $v\in\mathbb{R}^n$, $$v^T \nabla^2 J(\theta)\, v = \frac{1}{m}v^TX^TSXv = \frac{1}{m}(Xv)^TS(Xv) = \frac{1}{m}\sum_{i=1}^m s_i (Xv)_i^2 \ge 0,$$ since each $s_i = h_\theta(x^{(i)})(1-h_\theta(x^{(i)})) \ge 0$ (in fact $s_i \in (0, 1/4]$ because $h_\theta \in (0,1)$, with equality $s_i=1/4$ exactly at $h_\theta(x^{(i)})=1/2$). Every term is a nonnegative sum, so $v^T\nabla^2J(\theta)v \ge 0$ for all $v$, i.e. $\nabla^2 J(\theta) \succeq 0$. A symmetric PSD Hessian everywhere implies $J$ is convex.

Part (c)

($\Leftarrow$) Full rank implies strict convexity. Suppose $\mathrm{rank}(X)=n$, i.e. $Xv=0 \implies v=0$. If $v\ne0$, then $Xv\ne0$, so at least one coordinate $(Xv)_i\ne 0$. Since $\theta$ is finite (we are away from the separable/degenerate limit), $s_i = h_\theta(x^{(i)})(1-h_\theta(x^{(i)})) > 0$ strictly (as $h_\theta(x^{(i)})\in(0,1)$ strictly for finite $\theta^Tx^{(i)}$). Hence $v^T\nabla^2J(\theta)v = \frac1m\sum_i s_i(Xv)_i^2 > 0$ for every $v \ne 0$: the Hessian is positive definite everywhere, so $J$ is strictly convex.

($\Rightarrow$) Rank deficiency breaks strict convexity. If $\mathrm{rank}(X) < n$, there exists $v\ne 0$ with $Xv=0$. Then $(Xv)_i = 0$ for every $i$, so $$v^T\nabla^2 J(\theta)\, v = \frac1m\sum_i s_i \cdot 0^2 = 0 \quad \text{for every } \theta.$$ This means $J$ has exactly zero curvature along the direction $v$: explicitly, for any $\theta_0$, the function $t \mapsto J(\theta_0 + tv)$ is constant in $t$ (its derivative is $v^T\nabla J(\theta_0+tv)$, and one can check via the chain rule that $\theta^Tx^{(i)}$ is unchanged for all $i$ along this line since $Xv=0$, so $h_\theta(x^{(i)})$ — and hence $J$ itself — never changes). So $J$ is flat, not strictly convex, along $v$; the minimizer $\theta^*$ (if it exists) is non-unique, forming an affine line $\{\theta^* + tv\}$. $\blacksquare$

Problem 3 · Optimization Pathologies Gold

The Separability Catastrophe

Suppose the training data is linearly separable: there exists $\theta^*$ such that $y^{(i)}(\theta^{*T}x^{(i)}) > 0$ for every $i=1,\dots,m$ (using $y^{(i)}\in\{-1,+1\}$ labels for convenience here).

(a) Prove that for any $c>0$, $J(c\theta^*) < J(c'\theta^*)$ whenever $c > c' > 0$ — i.e. the loss strictly decreases as we scale the separating direction outward.

(b) Prove $\displaystyle\lim_{c\to\infty} J(c\theta^*) = 0$, and conclude that $\inf_\theta J(\theta) = 0$ but this infimum is never attained by any finite $\theta$.

(c) Given part (b), explain precisely why gradient ascent on the log-likelihood (equivalently, gradient descent on $J$) does not converge in the separable case, and state one standard remedy, justifying why it restores a finite, unique optimizer (cite Problem 2 in your justification).

Total: 12 points (4 + 4 + 4)

Show full solution

Part (a)

Write $z_i(c) = c\,\theta^{*T}x^{(i)}$. By separability, $y^{(i)}\theta^{*T}x^{(i)} > 0$ for each $i$; define $m_i := y^{(i)}\theta^{*T}x^{(i)} > 0$ (the "margin" of example $i$). The per-example loss in $\pm1$ notation is $\log(1+e^{-y^{(i)} c\,\theta^{*T}x^{(i)}}) = \log(1+e^{-cm_i})$ (this is algebraically the same cross-entropy term, rewritten with $y\in\{-1,1\}$). The function $c \mapsto \log(1+e^{-cm_i})$ has derivative $\frac{-m_ie^{-cm_i}}{1+e^{-cm_i}} < 0$ for every $c$, since $m_i>0$. So each term is strictly decreasing in $c$, hence so is their (positive-weighted) average $J(c\theta^*)$. Thus $c>c' \implies J(c\theta^*) < J(c'\theta^*)$.

Part (b)

As $c\to\infty$, $cm_i \to \infty$ for every $i$ (since $m_i>0$ fixed), so $e^{-cm_i}\to 0$ and $\log(1+e^{-cm_i}) \to \log 1 = 0$. Since there are finitely many ($m$) terms, the average also $\to 0$: $$\lim_{c\to\infty} J(c\theta^*) = \frac{1}{m}\sum_{i=1}^m \lim_{c\to\infty}\log(1+e^{-cm_i}) = 0.$$ Since $J(\theta) > 0$ strictly for every finite $\theta$ (each $\log(1+e^{-z})>0$ for finite $z$), and we've shown $J(c\theta^*)\to 0$, we get $\inf_\theta J(\theta) = 0$. But no finite $\theta$ achieves $J(\theta)=0$ exactly, since that would require $\log(1+e^{-y^{(i)}\theta^Tx^{(i)}})=0$ for every $i$, i.e. $y^{(i)}\theta^Tx^{(i)} = +\infty$ — impossible for finite $\theta$. So the infimum is approached only "at infinity," never attained.

Part (c)

Gradient descent seeks a stationary point $\nabla J(\theta)=0$. But by Part (a)/(b), $J$ is monotonically decreasing along the ray $\{c\theta^* : c>0\}$ with no minimum on that ray — so $\|\theta_t\|\to\infty$ as the iterates $\theta_t$ march along (an increasingly well-aligned proxy for) $\theta^*$, and $\nabla J(\theta_t)\to 0$ only in the limit, never exactly. The algorithm's parameters diverge in norm while the loss keeps (asymptotically) shrinking; there is no finite optimum to converge to.

The standard remedy is $\ell_2$-regularization0$. This works because the Hessian becomes $\nabla^2 J_\lambda(\theta) = \frac1m X^TSX + \frac{\lambda}{m}I$. By Problem 2(b), $X^TSX\succeq 0$ always, so adding $\lambda I \succ 0$ makes $\nabla^2J_\lambda(\theta) \succ 0$ strictly for every $\theta$ — regardless of the rank of $X$ or the separability of the data. $J_\lambda$ is therefore strictly convex everywhere, and since the quadratic penalty $\to\infty$ as $\|\theta\|\to\infty$ while $J(\theta)\ge 0$ is bounded below, $J_\lambda(\theta)\to\infty$ as $\|\theta\|\to\infty$ in every direction — so a finite global minimizer exists and is unique. $\blacksquare$

Problem 4 · Information Theory Platinum

Logistic Regression is the Maximum-Entropy Classifier

Among all conditional distributions $p(y\mid x)$ on $y\in\{0,1\}$, consider those satisfying the moment-matching constraints $$\mathbb{E}_{\hat p(x)}\big[\mathbb{E}_{p(y\mid x)}[y]\,x_j\big] = \mathbb{E}_{\hat p(x,y)}[y\, x_j] \quad \text{for } j=0,1,\dots,n,$$ where $\hat p$ denotes the empirical training distribution (and $x_0\equiv1$). Prove that the distribution $p(y\mid x)$ of maximum conditional entropy $$H(p) = -\sum_x \hat p(x)\sum_{y\in\{0,1\}} p(y\mid x)\log p(y\mid x)$$ subject to these constraints is exactly the logistic regression model $p(y=1\mid x) = g(\theta^Tx)$ for some $\theta$.

Total: 15 points

Show full solution

Setup: Lagrangian

We maximize $H(p)$ subject to (i) the moment constraints for each feature $j$, with multipliers $\theta_j$, and (ii) normalization $\sum_y p(y\mid x)=1$ for each $x$, with multipliers $\mu(x)$. Form the Lagrangian $$\mathcal{L} = -\sum_{x,y}\hat p(x)p(y\mid x)\log p(y\mid x) + \sum_j \theta_j\Big(\sum_{x,y}\hat p(x,y)\,y\,x_j - \sum_{x,y}\hat p(x)p(y\mid x)\,y\,x_j\Big) + \sum_x \mu(x)\Big(1-\sum_y p(y\mid x)\Big).$$

Stationarity

Differentiate with respect to $p(y\mid x)$ for a fixed $(x,y)$ pair and set to zero: $$\frac{\partial \mathcal{L}}{\partial p(y\mid x)} = -\hat p(x)\big(\log p(y\mid x) + 1\big) - \hat p(x)\,y\sum_j\theta_j x_j - \mu(x) = 0.$$ Assuming $\hat p(x) > 0$ (the point is observed), divide through by $-\hat p(x)$ and solve: $$\log p(y\mid x) = y\sum_j \theta_j x_j - 1 - \frac{\mu(x)}{\hat p(x)} \implies p(y\mid x) = \frac{1}{Z(x)}\exp\Big(y\,\theta^Tx\Big),$$ where $Z(x) = \exp\big(1+\mu(x)/\hat p(x)\big)$ absorbs all $x$-dependent (not $y$-dependent) terms — this is exactly the form of an exponential family with sufficient statistic $y\cdot x$.

Solving for the normalizer and identifying the sigmoid

Since $y\in\{0,1\}$, normalization requires $$Z(x) = \exp(0\cdot\theta^Tx) + \exp(1\cdot\theta^Tx) = 1 + e^{\theta^Tx}.$$ Hence $$p(y=1\mid x) = \frac{e^{\theta^Tx}}{1+e^{\theta^Tx}} = \frac{1}{1+e^{-\theta^Tx}} = g(\theta^Tx),$$ after multiplying numerator and denominator by $e^{-\theta^Tx}$. This is exactly the logistic regression hypothesis $h_\theta(x)$ from the lecture. Since the Lagrangian's objective (entropy) is concave and the constraint set is a convex polytope (affine equality constraints), this stationary point is the unique global maximizer.

Conclusion

Therefore, logistic regression is not an arbitrary parametric choice — it is forced upon us as the unique maximum-entropy conditional distribution consistent with matching the empirical feature-label correlations, i.e. the "least additional assumption" model given those moment constraints (a discrete-$y$ analogue of the well-known fact that the Gaussian is the max-entropy distribution given fixed mean and variance). $\blacksquare$

Problem 5 · Asymptotic Statistics Platinum

Fisher Information and the Precision of the Learned Boundary

Consider logistic regression with a single scalar feature (plus intercept), i.e. $\theta=(\theta_0,\theta_1)$ and $h_\theta(x) = g(\theta_0+\theta_1 x)$, fit by maximum likelihood on i.i.d. data $(x^{(i)},y^{(i)})$.

(a) Show that the Fisher information matrix for one observation is $$I(\theta) = \mathbb{E}\left[h_\theta(x)(1-h_\theta(x))\begin{pmatrix}1 & x\\ x & x^2\end{pmatrix}\right],$$ and relate this to the Hessian computed in Problem 2(a).

(b) Using the asymptotic normality of the MLE, $\sqrt{m}(\hat\theta - \theta^*) \xrightarrow{d} \mathcal{N}(0, I(\theta^*)^{-1})$, argue qualitatively (with a one-line justification from the formula in (a)) why training data concentrated near the true decision boundary ($\theta^{*T}x\approx 0$) yields a more precisely estimated $\hat\theta$ than data concentrated in the confident regions ($|\theta^{*T}x|$ large) — the opposite of the usual intuition that "confident, easy examples are more informative."

Total: 13 points (7 + 6)

Show full solution

Part (a)

The Fisher information for one observation is $I(\theta) = -\mathbb{E}[\nabla^2_\theta \log p(y\mid x;\theta)]$, i.e. the expected value of the negative Hessian of the per-example log-likelihood. From Problem 2(a)'s derivation applied to a single example, the per-example contribution to $-\nabla^2\ell^{(i)}(\theta)$ (before averaging over $i$) is exactly $$h_\theta(x)(1-h_\theta(x))\, xx^T,$$ where here $x=(1,x_1)^T$ so $xx^T = \begin{pmatrix}1 & x_1\\ x_1 & x_1^2\end{pmatrix}$. Taking expectation over the data distribution gives $$I(\theta) = \mathbb{E}\left[h_\theta(x)(1-h_\theta(x))\begin{pmatrix}1&x\\x&x^2\end{pmatrix}\right].$$ So $I(\theta)$ is precisely the population (expected) version of the empirical Hessian $\nabla^2 J(\theta)$ from Problem 2(a) (up to the sign convention: $\nabla^2 J = \frac1m X^TSX$ estimates $I(\theta)$ by the law of large numbers, since $J$ is the negative average log-likelihood). This is a general MLE fact: the sample Hessian of the negative log-likelihood is a consistent estimator of the Fisher information.

Part (b)

The weight $s(x) := h_\theta(x)(1-h_\theta(x))$ appearing inside the expectation in (a) is maximized exactly at $h_\theta(x)=1/2$ (by the identity $s(x)=\tfrac14 - (h_\theta(x)-\tfrac12)^2$, which is maximized at $s=1/4$ when $h_\theta(x)=1/2$, i.e. exactly when $\theta^Tx=0$ — the decision boundary from Problem 1(c)). As $|\theta^Tx|\to\infty$ (confident predictions), $h_\theta(x)\to 0$ or $1$, so $s(x)\to 0$: such points contribute vanishing weight to $I(\theta)$.

Since $\mathrm{Cov}(\hat\theta) \approx \tfrac1m I(\theta^*)^{-1}$, a larger $I(\theta^*)$ (more weight mass) gives a smaller (better) asymptotic covariance. Data points near the boundary ($\theta^{*T}x\approx0$) have $s(x)\approx 1/4$ — the maximum possible weight — and so contribute the most to $I(\theta^*)$, shrinking the estimation error of $\hat\theta$ the most. Confident, "easy" points (far from the boundary, where the model is already near-certain) contribute almost nothing to $I(\theta^*)$, because the model's prediction there is nearly insensitive to small perturbations of $\theta$ — flipping a coefficient slightly does not change $g(\theta^Tx)$ when $|\theta^Tx|$ is already huge. So, counter to the "confident examples are more informative" intuition common in casual reasoning about classifiers, it is precisely the ambiguous, boundary-straddling examples that are statistically most informative for pinning down $\theta$ — this is exactly the principle exploited by active-learning strategies like uncertainty sampling. $\blacksquare$

Problem 6 · Numerical Optimization Gold

Newton's Method as Iteratively Reweighted Least Squares (IRLS)

The Newton–Raphson update for maximizing $\ell(\theta)$ (equivalently minimizing $J(\theta)$) is $\theta^{new} = \theta^{old} - \big(\nabla^2 J(\theta^{old})\big)^{-1}\nabla J(\theta^{old})$.

Using the gradient $\nabla J(\theta) = \frac1m X^T(h_\theta(X)-y)$ and Hessian $\nabla^2J(\theta) = \frac1m X^TSX$ from Problem 2(a), prove that the Newton update can be rewritten exactly as the solution to a weighted least-squares problem: $$\theta^{new} = \arg\min_\theta \, (X\theta - z)^T S (X\theta - z), \qquad z := X\theta^{old} + S^{-1}(y-h_{\theta^{old}}(X)),$$ where $z$ is called the vector of "working responses." (Assume $S$ is invertible, i.e. every $h_\theta(x^{(i)}) \in (0,1)$ strictly.)

Total: 10 points

Show full solution

Step 1 — Write out the Newton step

Dropping the constant $1/m$ factors (they cancel between gradient and Hessian in the update), and writing $\theta^{old}$ as $\theta_0$ for brevity: $$\theta^{new} = \theta_0 - (X^TSX)^{-1}X^T(h_{\theta_0}(X) - y).$$

Step 2 — Introduce the working response $z$

Define $z = X\theta_0 + S^{-1}(y - h_{\theta_0}(X))$ as given. Then $$Sz = SX\theta_0 + (y-h_{\theta_0}(X)).$$ Substitute into the normal equations for weighted least squares, $X^TSX\theta = X^TSz$: $$X^TSz = X^TSX\theta_0 + X^T(y-h_{\theta_0}(X)) = X^TSX\theta_0 - X^T(h_{\theta_0}(X)-y).$$

Step 3 — Solve the normal equations

The weighted least-squares solution is $\theta^{new} = (X^TSX)^{-1}X^TSz$ (standard result: minimizing $(X\theta-z)^TS(X\theta-z)$ over $\theta$ gives normal equations $X^TSX\theta = X^TSz$, and $X^TSX$ is invertible whenever $X$ has full column rank, by Problem 2(c)). Substituting the expression for $X^TSz$ from Step 2: $$\theta^{new} = (X^TSX)^{-1}\Big[X^TSX\theta_0 - X^T(h_{\theta_0}(X)-y)\Big] = \theta_0 - (X^TSX)^{-1}X^T(h_{\theta_0}(X)-y),$$ which is exactly the Newton update from Step 1. Hence the two expressions for $\theta^{new}$ coincide. $\blacksquare$

Remark

This is why Newton's method for logistic regression is universally called Iteratively Reweighted Least Squares: at each iteration one solves an ordinary weighted linear regression against pseudo-targets $z$, with weights $S$ that adaptively down-weight points where the current model is already confident (small $s_i$) — echoing the Fisher-information intuition from Problem 5.

Problem 7 · Generative vs. Discriminative Models Platinum

Bayes Optimality Under Gaussian Class-Conditionals

Suppose $x\mid y=1 \sim \mathcal{N}(\mu_1,\Sigma)$ and $x\mid y=0\sim\mathcal{N}(\mu_0,\Sigma)$ (a shared covariance matrix $\Sigma$), with prior class probabilities $P(y=1)=\pi$, $P(y=0)=1-\pi$.

Prove that under this generative model (Gaussian Discriminant Analysis with shared covariance), the posterior $P(y=1\mid x)$ has exactly the logistic-regression form $g(\theta^Tx)$ for some $\theta$ depending on $\mu_0,\mu_1,\Sigma,\pi$ — and give $\theta$ explicitly. Conclude what this implies about when discriminative logistic regression and generative GDA should agree asymptotically, and state (without proof) one reason their finite-sample behavior can still differ.

Total: 14 points

Show full solution

Step 1 — Bayes' rule

By Bayes' rule, $$P(y=1\mid x) = \frac{p(x\mid y=1)P(y=1)}{p(x\mid y=1)P(y=1) + p(x\mid y=0)P(y=0)} = \frac{1}{1 + \dfrac{p(x\mid y=0)P(y=0)}{p(x\mid y=1)P(y=1)}}.$$ This already has the form $\dfrac{1}{1+e^{-a}}$ where $a = \log\dfrac{p(x\mid y=1)P(y=1)}{p(x\mid y=0)P(y=0)}$ — we must show $a$ is affine in $x$.

Step 2 — Compute the log-odds $a$

$$a = \log\frac{p(x\mid y=1)}{p(x\mid y=0)} + \log\frac{\pi}{1-\pi}.$$ Using the multivariate Gaussian density with shared $\Sigma$: $$\log\frac{p(x\mid y=1)}{p(x\mid y=0)} = -\tfrac12(x-\mu_1)^T\Sigma^{-1}(x-\mu_1) + \tfrac12(x-\mu_0)^T\Sigma^{-1}(x-\mu_0),$$ since the normalizing constants $(2\pi)^{-n/2}|\Sigma|^{-1/2}$ are identical (shared $\Sigma$) and cancel.

Step 3 — Expand the quadratic forms

Expand each quadratic form: $$(x-\mu_k)^T\Sigma^{-1}(x-\mu_k) = x^T\Sigma^{-1}x - 2\mu_k^T\Sigma^{-1}x + \mu_k^T\Sigma^{-1}\mu_k.$$ The $x^T\Sigma^{-1}x$ terms are identical for $k=0,1$ and cancel in the difference. What remains: $$-\tfrac12\Big[-2\mu_1^T\Sigma^{-1}x + \mu_1^T\Sigma^{-1}\mu_1\Big] + \tfrac12\Big[-2\mu_0^T\Sigma^{-1}x + \mu_0^T\Sigma^{-1}\mu_0\Big]$$ $$= (\mu_1-\mu_0)^T\Sigma^{-1}x - \tfrac12\mu_1^T\Sigma^{-1}\mu_1 + \tfrac12\mu_0^T\Sigma^{-1}\mu_0.$$ This is affine in $x$: linear coefficient $\Sigma^{-1}(\mu_1-\mu_0)$, plus a constant.

Step 4 — Assemble $\theta$

Combining with the prior log-odds term from Step 2: $$a = \underbrace{\big(\Sigma^{-1}(\mu_1-\mu_0)\big)^T}_{\theta_{1:n}^T} x \;+\; \underbrace{\left[-\tfrac12\mu_1^T\Sigma^{-1}\mu_1 + \tfrac12\mu_0^T\Sigma^{-1}\mu_0 + \log\frac{\pi}{1-\pi}\right]}_{\theta_0}.$$ So indeed $P(y=1\mid x) = g(\theta_0 + \theta_1^Tx)$ with $$\theta_1 = \Sigma^{-1}(\mu_1-\mu_0), \qquad \theta_0 = \tfrac12(\mu_0^T\Sigma^{-1}\mu_0 - \mu_1^T\Sigma^{-1}\mu_1) + \log\frac{\pi}{1-\pi}.$$ This is exactly logistic regression's functional form, but with $\theta$ derived analytically from Gaussian parameters rather than fit by MLE on $\theta$ directly. $\blacksquare$

Conclusion

Because GDA's induced posterior is a special case of the logistic model, whenever the true data-generating process really is Gaussian-with-shared-covariance, both GDA and (correctly-fit, asymptotically many samples) logistic regression converge to the same Bayes-optimal decision rule — logistic regression is a strictly weaker (fewer assumptions) but still correctly-specified model in this case, so it is asymptotically consistent for the true $\theta$ too. However, with finite samples the two can disagree: GDA additionally assumes and exploits Gaussianity to estimate $\mu_0,\mu_1,\Sigma$ efficiently, so if the Gaussian assumption truly holds, GDA typically needs fewer samples to reach a given accuracy; but GDA's estimates become biased/inconsistent if the true class-conditionals are not Gaussian, whereas logistic regression — because it directly models only the posterior's functional form — remains asymptotically consistent under a much broader family of class-conditional distributions (any exponential family with shared natural-parameter structure yields the same logistic posterior form).

A Sharp Bound on the Sigmoid's Lipschitz Constant, and a Safe SGD Step Size

(a) Prove that $g'(z) = g(z)(1-g(z)) \le \tfrac14$ for all $z\in\mathbb{R}$, with equality iff $z=0$. Conclude that $g$ is $\tfrac14$-Lipschitz: $|g(z_1)-g(z_2)| \le \tfrac14|z_1-z_2|$.

(b) Using Part (a) and Problem 2(a), show that for any single training example $(x,y)$ with $\|x\|_2 \le R$, the per-example loss $\ell_i(\theta) = -\big[y\log h_\theta(x) + (1-y)\log(1-h_\theta(x))\big]$ has gradient that is $\tfrac{R^2}{4}$-Lipschitz in $\theta$: $\|\nabla \ell_i(\theta_1) - \nabla\ell_i(\theta_2)\|_2 \le \tfrac{R^2}{4}\|\theta_1-\theta_2\|_2.$

(c) Standard convex optimization theory guarantees that gradient descent with a fixed step size $\alpha \le 1/L$ on an $L$-smooth convex function converges monotonically. Using (b), state a data-dependent, provably safe learning rate $\alpha$ for (stochastic) gradient descent on the full empirical loss $J(\theta) = \frac1m\sum_i \ell_i(\theta)$, and justify it.

Total: 12 points (4 + 4 + 4)

Part (b)

From Problem 2(a) restricted to one example, $\nabla_\theta \ell_i(\theta) = (h_\theta(x)-y)\,x$ and $\nabla^2_\theta \ell_i(\theta) = h_\theta(x)(1-h_\theta(x))\, xx^T = g'(\theta^Tx)\, xx^T$. The spectral norm of $xx^T$ is $\|x\|_2^2 \le R^2$ (its only nonzero eigenvalue is $\|x\|_2^2$, with eigenvector $x$). Combined with Part (a)'s bound $g'(\theta^Tx)\le\tfrac14$: $$\|\nabla^2 \ell_i(\theta)\|_{op} = g'(\theta^Tx)\,\|x\|_2^2 \le \tfrac14 R^2 \quad \text{for every } \theta.$$ A twice-differentiable function whose Hessian has operator norm bounded by $L$ everywhere has $L$-Lipschitz gradient (standard consequence of the mean value inequality applied to $\nabla\ell_i$ along the segment $[\theta_1,\theta_2]$). Hence $\nabla\ell_i$ is $\tfrac{R^2}{4}$-Lipschitz.

Part (c)

Since $J = \frac1m\sum_i \ell_i$ is an average of functions each with gradient Lipschitz constant $\le R^2/4$, $\nabla J$ is also $\tfrac{R^2}{4}$-Lipschitz (Lipschitz constants of a convex combination are bounded by the max of the individual constants, by the triangle inequality applied termwise). So $J$ is $L$-smooth with $L = R^2/4$, where $R = \max_i \|x^{(i)}\|_2$.

Therefore the theoretically safe fixed step size is $$\alpha = \frac{1}{L} = \frac{4}{R^2} = \frac{4}{\max_i \|x^{(i)}\|_2^2}.$$ With this choice, standard descent-lemma arguments guarantee $J(\theta_{t+1}) \le J(\theta_t) - \tfrac{\alpha}{2}\|\nabla J(\theta_t)\|_2^2$, so $J$ decreases monotonically every iteration and gradient descent is guaranteed not to diverge or oscillate — a fully data-derived (no hand-tuning) certificate for a safe learning rate, in sharp contrast to the typical practice of tuning $\alpha$ by trial and error. $\blacksquare$
